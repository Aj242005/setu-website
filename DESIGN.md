# Daylight field notes

Extend the Android visual system, not a new brand. Background #F4F6F2, paper
#FCFDF9, ink #202A23, forest #195A40, leaf #DBEDBD, secondary #53664B,
rules #D9E1D4. System sans, 16–18px body, display up to 88px. All text remains
selectable; narrow columns for reading, generous chapter spacing.

An evidence-first field journal: open with the app and one real screenshot,
explain the collection journey, show actual outage evidence, then make the beta
download and responsible contribution steps concrete. No fake maps, charts,
reviews, counters or stock dashboard tiles. Use the existing SETU mark.

Desktop pairs editorial copy with an actual phone capture; mobile places the
action before the image. One quiet reveal of the screenshot only, disabled for
reduced motion. Visible focus, 44px controls, no hover-only content. Light is
the default even on dark-system devices, matching the requested presentation.
